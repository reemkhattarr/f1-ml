# F1 Tire Strategy

Interactive demo of a tyre-strategy model trained on 2022–2024 F1 timing data.
Pick a race and driver, scrub through the laps, and compare the model's pit /
compound recommendation with what the team actually did.

The demo reads a pre-built dataset (no live data calls). Source code and full
write-up: see the project repository.
